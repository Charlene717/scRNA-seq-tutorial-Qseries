# 基礎 06 · 胰島第二彈：標籤轉移與兩套答案的對質

**難度**：★ ｜ **預估時間**：0.5–1 個工作天 ｜ **對應 Q 系列**：Q2・註解、Q3・整合 ｜ **前置**：先完成基礎05（本題要用你的 Baron 物件當 reference） ｜ **對應練習腳本**：`R/03_annotate.R`、`R/04_multipatient.R`

**原題**：B 系列 基礎09（本卡為 Q 系列改寫版，B 系列原檔未更動）

## 背景與研究主題

Muraro 等人（2016）用 SORT-seq（FACS 分選＋CEL-seq2）做了另一份人類胰島圖譜——跟基礎05 的 Baron（inDrop）同組織、同物種、不同平台、不同人。這給了你一個難得的機會：**你手上已經有一份自己註解過的胰島資料**，可以拿它當 reference，用 Seurat 的 label transfer（`FindTransferAnchors` + `TransferData`）自動註解新資料，再跟你自己從頭分群註解的結果對質。註解從此有三個消息來源：自己查 marker、reference 轉移、原論文標籤——它們不一致的地方，才是這題真正要教的東西。你的研究主題：

1. 用 Baron 當 reference 做 label transfer，Muraro 的細胞被貼上什麼標籤？prediction score 高低分布如何？
2. inDrop 與 CEL-seq2 兩個平台差在哪？這些差異怎麼影響 anchor 的品質？
3. 轉移標籤與你自己的分群註解在哪些細胞上分歧？分歧時你怎麼裁決誰對？

## 資料集

- **GSE85241**（Muraro；SORT-seq / CEL-seq2 平台）。人類胰島，4 donors，csv counts + barcodes csv。
- 下載：GEO accession 頁 Supplementary files。
- 格式注意：矩陣有 **3,072 欄，含未過 QC 的細胞**（384-well 盤 × 8 盤的所有 well 都在裡面），載入後一切以 `dim()` 為準，別急著跟論文細胞數對表。基因列名與 donor 資訊的編碼方式以你載入後實際看到的為準——列名若帶染色體之類的後綴要先清理，donor 通常藏在欄名前綴裡，先 `head(colnames(mat))` 偵查。

## 任務

### 階段 A：讀入、QC 與自己的註解（對應 Q2 全流程）

1. 讀入 csv，偵查並清理基因列名、從欄名解析 donor 存進 metadata。`dim()` 記錄原始規模。
2. QC：3,072 個 well 裡有一批根本是空 well 或壞細胞，nCount/nFeature 分布會呈現明顯的「兩個世界」——閾值三件事照舊，並記錄過濾掉多少。SORT-seq 是 plate-based，分布跟 inDrop 長得不一樣，值得跟你基礎05 的 QC 圖並排看一眼。
3. 標準流程到 UMAP＋分群，用你基礎05 查過的胰島 marker（GCG/INS/SST/PPY、acinar、ductal、內皮、stellate、免疫）快速做一版**自己的註解**——這版是階段 C 對質用的「消息來源一」。

### 階段 B：label transfer（對應 Q3・整合）

4. 載入你基礎05 完成的 Baron 物件（含你的最終註解欄）。確認兩邊 normalization 一致（都用 LogNormalize 或都用 SCT——混用是常見死因）。
5. `FindTransferAnchors(reference = baron, query = muraro, dims = 1:30)` → `TransferData()` 拿到 `predicted.id` 與 prediction score，掛回 metadata。參數（dims、features、reduction）三件事照規矩記。
6. 檢視轉移品質：score 的分布直方圖、score 低的細胞落在 UMAP 哪裡、哪些型別平均 score 最低。回答：inDrop（3' UMI、淺）與 CEL-seq2（3' UMI、plate、FACS 分選）的平台差異，可能讓哪些基因在兩邊表現不一致，從而傷到 anchor？（提示：深度、偵測靈敏度、分選對組成的影響。）

### 階段 C：三方對質（對應 Q2・註解、Q3・整合）

7. 交叉表一：你的註解 × `predicted.id`。交叉表二：`predicted.id` × 分群 cluster。找出分歧最大的 2–3 個群。
8. 對每個分歧群裁決：畫該群的關鍵 marker DotPlot，判斷是（a）你的註解錯、（b）轉移錯（score 也低嗎？）、（c）reference 裡根本沒有這個型別（Baron 有 14 型，Muraro 有沒有 Baron 缺的？）、還是（d）粒度不同。寫 200–400 字筆記：label transfer 什麼時候可信、什麼時候必須回到 marker 證據？

## 繳交物

1. 可重跑的 R 專案（含基因名清理與 donor 解析程式碼）。
2. 圖：QC 分布（含過濾前後）、自己註解的 UMAP、`predicted.id` 上色 UMAP、prediction score 分布圖與 FeaturePlot、分歧群 marker DotPlot（英文標籤）。
3. 分析筆記：參數三件事＋兩張交叉表＋逐群裁決紀錄。
4. label transfer 信任邊界筆記（200–400 字）。

## 自我檢核點

- [ ] 載入後以 `dim()` 為準，QC 前後的細胞數都有記錄，且能解釋 3,072 欄的由來
- [ ] 基因名與 donor 解析有偵查過程紀錄，不是矇著頭硬跑
- [ ] reference 與 query 的 normalization 方式一致，且寫在筆記裡
- [ ] score 低的細胞有被追查（在哪、是誰、為什麼），不是只報平均分
- [ ] 每個分歧群都有 marker 證據支持的裁決，且分得清 (a)–(d) 四種情況

## 提示（卡關再看）

<details><summary>提示 1：TransferData 骨架</summary>
`anchors <- FindTransferAnchors(reference = baron, query = muraro, dims = 1:30)`；`pred <- TransferData(anchorset = anchors, refdata = baron$celltype, dims = 1:30)`；`muraro <- AddMetaData(muraro, pred)`。`predicted.id` 是標籤、`prediction.score.max` 是信心。兩物件都先各自跑完 NormalizeData/FindVariableFeatures 再找 anchor。
</details>

<details><summary>提示 2：score 低的細胞怎麼解讀</summary>
三種常見劇本：(1) doublet 或低品質細胞——回頭看它的 QC 指標；(2) reference 沒有的型別——它自成一群且 marker 清楚，只是 Baron 那邊沒得對；(3) 兩個相近型別間的騎牆派（如 α/β 交界）——score 分散在兩個型別上。用 `prediction.score.*` 各欄攤開看，不要只看 max。
</details>

<details><summary>提示 3：交叉表怎麼讀</summary>
`table(muraro$my_anno, muraro$predicted.id)` 的對角線是共識，離對角線的大格才是重點。先處理「整群系統性不一致」（通常是粒度或型別缺席），再看「單群裡少數細胞流失」（通常是 doublet 或邊界細胞）。
</details>

## 進階挑戰

- 反向轉移：用 Muraro 當 reference 註解 Baron，看分歧是否對稱——不對稱本身就透露兩份資料誰在哪個型別上更有把握。
- 把 4 位 donors 分開評估 prediction score，看轉移品質是否有 donor 差異，連回基礎05 的 donor 效應觀察。
- reference 選擇對註解結果的影響，在 B 系列 進階01（GBM 惡性判定的 reference 敏感度）是正式的方法學題目；圖譜級的 mapping（幾十萬細胞的 reference）則見 B 系列 進階30。
