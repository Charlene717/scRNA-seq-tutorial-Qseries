# 實作練習題

看完《快速上手篇》之後的動手關卡，共 23 題：**基礎 9 題**把課程裡的某一段流程換一份資料練熟，**進階 14 題**是完整的再分析專案，最理想的情況是真的長出一篇可投稿的研究。

這些題目跟課程 R 腳本結尾的「▶ 練習」不一樣。那些是隨堂練習：換個參數重跑、把某張圖換個切法，幾十分鐘就做得完。這裡的題目要你自己找資料、自己下載、自己決定參數、自己寫報告，半天到三個工作天一題。

**所有題目用的都是課程沒教過的資料。** 課堂上示範用的兩份資料（Q2 的 10x GBM 5k、Q3 的 GSE84465）在這裡一份都不會出現——練習如果還是同一批資料，練到的只是重跑一次示範。這 23 題用 23 個不同的公開資料集。

## 怎麼用這個資料夾

- [`基礎/`](基礎) —— 9 張基礎題卡（md 與同名 .docx 內容相同，看哪個順手都可以）
- [`進階/`](進階) —— 14 張進階題卡
- [`進階/_從練習到投稿指南.md`](進階/_從練習到投稿指南.md) —— 所有進階題共用：再分析的正當切入點、投稿的最低標準、期刊層級怎麼看
- [`資料集總覽.md`](資料集總覽.md) —— 每個資料集的 accession、規模、格式、下載方式

每張題卡的結構固定：背景與研究主題 → 資料集 → 任務（分階段）→ 繳交物 → 自我檢核點 → 提示（卡關再看）→ 參考文獻。進階題多兩節：**真實數據關卡**（讀檔之前的格式解剖、決策日誌）與**發表路徑**（訊號分類、驗證設計、novelty 查證、目標期刊層級）。

## 進階題的階段 D：把課程教的分析全部用上

課程裡 Q3 把下游六條路並排介紹了一遍。每一張進階題卡的**階段 D 要你在同一份資料上把它們接成一條線**：

| 步驟 | 你要做的事 | 課程腳本 |
|---|---|---|
| D1 | pseudobulk 差異表達，統計單位是病人；每個細胞型別各自校正 | `R/06a_pseudobulk_gsea.R` |
| D2 | 同一組對比再跑 cell-level DE，用三道防線比較兩者結論差多少 | `R/06b_cell_level_de.R` |
| D3 | GSEA／ORA；ORA 的背景用「這次測到的基因」，報 p.adjust | `R/06a_pseudobulk_gsea.R` |
| D4 | CellChat 兩條件分開建物件再比較，並做組成校正 | `R/07_cellchat.R` |
| D5 | 軌跡：起點要有生物學理由，並排除「只是把細胞週期畫一遍」 | `R/08_trajectory.R` |
| D6 | PROGENy 路徑活性 + SCENIC／decoupleR regulon 活性 | `R/09_activity.R` |
| D7 | 建 signature、MuSiC 反卷積 bulk 隊列、KM 與 Cox 臨床驗證 | `R/10_deconv_survival.R` |

D7 放在最後是刻意的：**沒有這一步，十幾位病人的單細胞觀察就只是描述**。腫瘤題接對應的 TCGA 專案；肝硬化與肺纖維化沒有 TCGA 對應，要你自己上 GEO 找一個帶臨床變項的 bulk 隊列——那個查找過程本身就是題目的一部分。

**這七步不是每一步在每份資料上都成立。** 進階11 只分選了 T 細胞，完整的通訊網路做不了；進階12、進階13 沒有惡性細胞，inferCNV 只能當陰性對照跑。遇到做不了的步驟不要跳過不提，**寫下為什麼做不了**——那句解釋跟做得出來的圖一樣重要，也是檢核點之一。

## 建議的做題順序

**先暖身**：基礎01 → 基礎02。第一題把 Q2 的流程換一份資料獨立走完並寫成報告；第二題不看任何教學再做一遍，那才知道自己真的會了沒有。想再紮實一點就接基礎03 到基礎06；想先摸 Q3 的工具就接基礎07 到基礎09。

**進階入門三部曲**：進階01 → 進階02 → 進階03。這三題是方法學的源頭（Tirosh 的黑色素瘤、Puram 的 p-EMT、van Galen 的 AML），課程裡教的惡性判定與狀態評分都源自它們。走完會第一次遇到「課堂給的答案不是唯一答案」。

**然後挑一條線做完**，每條 3–4 題：

- 惡性狀態與異質性：進階01 → 進階02 → 進階04
- 微環境與通訊：進階05 → 進階06 → 進階10 → 進階09
- 病人層級統計與大隊列：進階07 → 進階08 → 進階14
- 非腫瘤疾病：進階12 → 進階13（惡性判定改當陰性對照，反卷積要自己找隊列）
- 單一族群做深：進階11（Smart-seq2 的深度優勢，也是唯一一題要你說明「通訊分析為什麼做不了」）

一條線做完就是一份完整的再分析工作。動手之前先讀[《從練習到投稿指南》](進階/_從練習到投稿指南.md)。

## 所有題目共通的規矩

- `set.seed(1234)`；用 RStudio Project + renv；相對路徑，不要寫 `setwd()` 絕對路徑。
- 每一個自訂參數（QC 閾值、resolution、nPC…）都要答得出**數字、理由、紀錄**三件事。
- 繳交的圖用英文標籤（投稿習慣）；分析筆記中文即可。
- 進階題一律開一份 `decisions.md` 記決策日誌：發現了什麼 → 有哪些選項 → 你選了什麼 → 為什麼。這份日誌是繳交物，也是之後論文 Methods 的草稿。
- 階段 D 做不了的步驟，要寫下為什麼做不了。那是評分點，不是可以略過的地方。
