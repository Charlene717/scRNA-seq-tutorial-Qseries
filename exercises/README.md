# Q 系列 · 實作練習題（選集）

**版本**：v2.0 ｜ 2026-09-06 ｜ 配套 Q 系列《快速上手篇》Q1–Q4
**來源**：從 B 系列實作練習題庫（80 題）挑出 23 題改寫成 Q 系列版。**B 系列原檔完全未更動**，本資料夾是獨立的一份副本。

## 三個選題原則

**一、資料集全部是新的。** 課堂腳本用的是 10x GBM 5k（Q2）與 GSE84465（Q3），這兩份**刻意不收**——練習題如果還是同一批資料，練到的只是重跑一次課堂示範。這 23 題用的是 23 個不同的公開資料集，沒有一個在課程裡出現過。

**二、進階題都是「一篇論文的規模」，不是單一技能的小單元。** 每一題都是多病人、多樣本的真實資料，從讀檔到臨床驗證走完整條線，1.5–3 個工作天。原本 B 系列裡像「反卷積與存活分析」這種單一工具的題目不另外收——它變成每一題的收尾階段（見下）。

**三、每一題都用得到課程教過的全部分析。** 這是 v2 最大的改動：每張進階卡都加了**階段 D**，把 Q3 下游六條路接成一條線。

## 階段 D：課程全套分析（每張進階卡都必做）

| 步驟 | 內容 | 練習腳本 |
|---|---|---|
| D1 | pseudobulk 差異表達，統計單位是病人；每個細胞型別各自校正 | `R/06a_pseudobulk_gsea.R` |
| D2 | 同一組對比再跑 cell-level DE，用三道防線比較兩者結論差多少 | `R/06b_cell_level_de.R` |
| D3 | GSEA／ORA；ORA 的背景用「這次測到的基因」，報 p.adjust | `R/06a_pseudobulk_gsea.R` |
| D4 | CellChat 兩條件分開建物件再比較，並做組成校正 | `R/07_cellchat.R` |
| D5 | 軌跡：起點要有生物學理由，並排除「只是細胞週期」 | `R/08_trajectory.R` |
| D6 | PROGENy 路徑活性 + SCENIC／decoupleR regulon 活性 | `R/09_activity.R` |
| D7 | 建 signature、MuSiC 反卷積 bulk 隊列、KM 與 Cox 臨床驗證 | `R/10_deconv_survival.R` |

D7 是刻意放在每一題最後的：**沒有這一步，十幾位病人的單細胞觀察只是描述**。腫瘤題接對應的 TCGA 專案，非腫瘤題（肝硬化、肺纖維化）沒有 TCGA 對應，要自己上 GEO 找一個帶臨床變項的 bulk 隊列——那個查找過程本身就是題目的一部分。

而且這七步**不是每一步在每份資料上都成立**。肝癌 T 細胞那題只分選了 T 細胞，完整通訊網路做不了；肝硬化與肺纖維化沒有惡性細胞，inferCNV 只能當陰性對照跑。卡片要求學生寫下「為什麼這一步做不了」——那句解釋跟做得出來的圖一樣重要。

## 建議路線

**課後暖身（一週內）**：基礎01 → 基礎02。第一題把 Q2 的流程換一份資料獨立走完並寫成報告；第二題不看任何教學再做一遍。想再紮實一點就接基礎03 到基礎06；想先摸 Q3 的工具就接基礎07 到基礎09。

**進階入門三部曲**：進階01 → 進階02 → 進階03。這三題是方法學的源頭（Tirosh 的黑色素瘤、Puram 的 p-EMT、van Galen 的 AML），課程裡教的惡性判定與狀態評分都源自它們；走完會第一次遇到「課堂給的答案不是唯一答案」。

**之後挑一條主線做完（每條 3–4 題）**：

- 惡性狀態與異質性：進階01 → 進階02 → 進階04
- 微環境與通訊：進階05 → 進階06 → 進階10 → 進階09
- 病人層級統計與大隊列：進階07 → 進階08 → 進階14
- 非腫瘤疾病：進階12 → 進階13（惡性判定改當陰性對照，反卷積要自己找隊列）
- 單一族群做深：進階11（Smart-seq2 的深度優勢，也是唯一一題要你說明「通訊分析為什麼做不了」）

一條主線做完就是一份完整的再分析工作，最理想的情況是真的長出可投稿的新生物意義。動手前先讀 `進階/_從練習到投稿指南.md`。

## 通用規範（所有題目適用）

- `set.seed(1234)`；用 RStudio Project + renv；相對路徑，不寫 `setwd()` 絕對路徑。
- 每一個自訂參數（QC 閾值、resolution、nPC…）都要答得出**數字、理由、紀錄**三件事。
- 繳交的圖用英文標籤（投稿習慣）；分析筆記中文即可。
- 進階題一律開 `decisions.md` 記決策日誌：發現了什麼 → 有哪些選項 → 選了什麼 → 為什麼。這份日誌是繳交物，也是論文 Methods 的草稿。
- 階段 D 做不了的步驟，要寫下為什麼做不了——那是評分點，不是可以略過的地方。
