# 進階 05 · 乳癌亞型與腫瘤微環境

**難度**：★★★ ｜ **預估時間**：2 個工作天 ｜ **對應 Q 系列**：Q3・整合、Q3・通訊、Q3・下游路線（乳癌戰法）｜ **對應練習腳本**：`R/01`–`R/10` 全套（階段 D 逐步對應），重點在 `R/04_multipatient.R` ｜ **資料集**：GSE176078 / SCP1039（本題獨用）

**原題**：B 系列 進階06（本卡為 Q 系列改寫版，B 系列原檔未更動）

## 背景與研究主題

Wu 等人（2021）發表的乳癌單細胞圖譜涵蓋 26 顆腫瘤、三個臨床亞型（11 ER+、5 HER2+、10 TNBC）。乳癌的臨床亞型是按腫瘤細胞的受體狀態定的，但治療反應的差異很大一部分寫在**微環境**裡——CAF 的組成、免疫浸潤的深淺、腫瘤與免疫細胞之間的對話。這題是 Q3・下游路線 乳癌戰法的完整演練：惡性細胞與微環境**分開處理**，通訊分析當偵探工具而非結論。你的研究主題：

1. 不同臨床亞型的腫瘤，微環境組成（CAF 亞群、免疫浸潤）差在哪裡？
2. TNBC 與 ER+ 的「腫瘤—微環境對話」有什麼系統性差異？這個差異有多少是細胞組成造成的假象？
3. 亞型間的 CAF／免疫訊號，哪一個扛得住穩健性檢查、值得往發表推？

## 資料集

- **GSE176078**（10x，~100,064 cells／26 腫瘤：11 ER+、5 HER2+、10 TNBC）；亦可從 **Broad Single Cell Portal SCP1039** 下載（含作者 metadata csv，帶病人與細胞型別註解）。
- 格式：10x 三件套 + metadata csv。
- **本題務必取 6–8 顆腫瘤的子集**（資料集總覽有明訂）：每個亞型至少 2 顆。全量 10 萬細胞不是本題目標。
- 作者 metadata 的細胞註解可以拿來「對答案」，但階段 A 的註解請自己做。

## 真實數據關卡

真實資料在你跑第一行 Seurat 之前就開始出題。這一節照做並記錄：

1. **兩來源、一個決定**：GEO 與 SCP1039 都能下載，但檔案打包方式、檔名、barcode 寫法與 metadata 欄位不保證互相對得上。先各看一眼檔案清單（別急著全下載），**選定一個來源就從一而終**；若非混用不可（例如矩陣取自 GEO、metadata 取自 SCP1039），必須抽樣驗證 barcode 能一對一對齊，並記錄對不上的比例。
2. **子集選擇偏誤**：6–8 顆怎麼挑本身就是研究決策。只挑細胞數最多的腫瘤，等於偏向取樣好、解離順利的檢體；只求亞型平衡，可能把某亞型裡的極端樣本挑進來。寫下你的選擇規則（各亞型 ≥2、細胞數門檻、有沒有排除特殊處理的樣本）與**這個規則可能引入什麼偏誤**——階段 C 會回頭檢驗它。
3. **10 萬細胞的記憶體策略**：即使只用子集，全矩陣讀入的瞬間就可能吃掉十幾 GB。策略：能按樣本讀就按樣本讀、載入即轉稀疏矩陣（dgCMatrix）、子集完成立刻 `rm()` + `gc()`、每個階段落地一個 RDS 免得重跑。記下你的物件在各步驟的大小（`object.size`）。
4. **決策日誌**：開一個 `decisions.md`，凡是「資料逼你做的決定」都記一筆：發現了什麼 → 選項 → 你選了什麼 → 理由。這份日誌是繳交物，也是你之後寫論文 Methods 的草稿。

## 任務

### 階段 A：子集選擇與整合策略（Q3・整合、Q3・下游路線）

1. 讀樣本清單，按你在真實數據關卡定下的規則選 6–8 顆腫瘤（各亞型 ≥2），選擇理由進 decisions.md。
2. 讀入、合併、QC（每個閾值：數字、理由、紀錄），先不整合跑一版 UMAP，觀察哪些群按病人分。
3. 決定整合範圍並執行：Q3・整合的答案是「**惡性按病人分是生物學、微環境該整合**」——先用 marker + inferCNV（免疫／內皮當 reference）把惡性上皮與微環境分開（惡性判定靠 CNV，不是 marker），再只對微環境細胞整合（Harmony 或 anchors）。

### 階段 B：亞型間微環境比較（Q3・差異表達 概念、Q3・下游路線 乳癌戰法）

4. 對整合後的微環境做精細註解：至少分出 T/NK、B、myeloid、內皮，以及 **CAF 並往下分亞群**（myCAF/iCAF 方向的 marker：ACTA2、FAP、PDGFRA、CXCL12…）。跟作者 celltype 欄對答案，差異寫進筆記。
5. 比較亞型間微環境組成：每顆腫瘤算各型別比例，按亞型分組畫圖。統計單位是**腫瘤（病人）不是細胞**——你只有 6–8 個點，誠實面對「描述趨勢」與「統計檢定」的差別。
6. 用 CellChat（或 CellPhoneDB）對 TNBC 與 ER+ 分別建物件、跑兩物件比較：哪些 pathway 在 TNBC 中更強？惡性細胞對誰「說話」最多？

### 階段 C：亞型訊號的深挖與發表評估（發表導向；Q3・通訊、Q3・下游路線）

7. 從階段 B 挑一個亞型間差異最強的訊號（CAF 亞群組成、某群免疫浸潤深淺、或一組 L-R pair 擇一）深挖：狀態層級的 DE、跨腫瘤一致性（同亞型內每顆腫瘤都看得到嗎？）。
8. 穩健性三連發：(a) 換一組符合同樣規則的腫瘤子集重跑組成比較——訊號還在嗎？這是對你子集偏誤的直接檢驗；(b) 通訊差異做組成混淆檢查（下採樣到相同組成重跑，或至少畫 per-cell 表達分病人驗證；Q3・通訊 踩雷區：**通訊是從表達推論的，不是實測**）；(c) 換 resolution 或換打分方式。
9. 寫「發表路徑」評估（見下節，300–500 字）。

### 階段 D：走完 Q 系列的下游全套（必做）

Q3 把下游六條路並排介紹過一遍；這一題要你在同一份資料上把它們接成一條線。A–C 已經做完整合、
惡性判定與主訊號的挑選，D 是把那個訊號推到「能寫進論文」的程度。

**這七步不是每一步在每份資料上都成立。做不了的那一步不要跳過不提——寫下為什麼做不了
（沒有惡性細胞、只分選了單一族群、找不到對得上的 bulk 隊列…）。那句解釋跟做得出來的圖一樣重要。**

- **D1 pseudobulk 差異表達（`R/06a_pseudobulk_gsea.R`）**：對比是ER+ 與 TNBC（統計單位是病人）。
  每個主要細胞型別各跑一次 pseudobulk + DESeq2、各自校正；不要把所有型別的 p 值倒在一起再校正一次。
  細胞數太少跑不動的型別要列出來說明，不是默默略過。
- **D2 兩種 DE 對照（`R/06b_cell_level_de.R`）**：同一組對比再用 cell-level DE 跑一次，套上三道防線
  （病人共變量、逐病人一致性、標籤置換），比較兩者的結論差多少。差很多的時候，可信的是 pseudobulk——
  把差異寫進報告，這是最能看出你懂不懂統計單位的一段。
- **D3 富集（`R/06a` §4）**：對排序後的基因清單跑 GSEA（Hallmark 起手），需要 ORA 時背景基因集用
  「這次真的測到的基因」而不是全基因體。報 p.adjust，不要報原始 p。
- **D4 細胞通訊（`R/07_cellchat.R`）**：至少要看惡性上皮 ↔ myeloid、惡性上皮 ↔ CAF。兩個條件**各建一個 CellChat 物件分開跑再比較**，
  不要合成一個物件。差異出來之後一定要做組成校正：下採樣到相同細胞組成重跑，訊號還在嗎？
- **D5 軌跡（`R/08_trajectory.R`）**：CAF 的 iCAF 與 myCAF 連續軸，或 myeloid 的單核到 TAM 軸。起點要有生物學理由（marker 或已知階層），不是看圖挑一個角落；
  用 tradeSeq 找沿軌跡變化的基因，並回答「這條軌跡是不是只是把細胞週期畫了一遍」。
- **D6 路徑與轉錄因子活性（`R/09_activity.R`）**：用 PROGENy 算路徑活性、SCENIC（或 decoupleR 的 TF 網路）
  算 regulon 活性，做同一組對比。這一步的價值在於：DE 給你一串基因，活性告訴你「這些基因是被誰開起來的」。
- **D7 反卷積與臨床驗證（`R/10_deconv_survival.R`）**：用你自己的註解建 signature matrix，MuSiC 反卷積
  TCGA-BRCA（依 PAM50 分層再做，不要混在一起），把 A–D 找到的族群或狀態比例接到臨床變項上做 KM 與 Cox（放進期別、年齡等共變量）。
  反卷積的前提要自己檢查：signature 裡的細胞型別在該 bulk 組織裡真的存在嗎？估出來的比例加總與相對大小合理嗎？
  **這是把十幾位病人的觀察帶到數百位病人身上檢驗的唯一出口——沒有這一步，你的發現只是描述。**

## 發表路徑

讀 `_從練習到投稿指南.md` 後回答：

- 你的亞型間 CAF／免疫訊號屬於指南第二節的哪一類？它通過「以腫瘤為單位仍成立」與換子集重跑了嗎？6–8 顆的 n 撐得起什麼強度的句子？

- **novelty 定位**：乳癌微環境單細胞文獻極厚（原論文本身就做了 CAF 分型）——用 PubMed 查你的訊號有沒有人做過；你的角度（亞型間的系統比較？某個被原論文一筆帶過的亞群？）還新嗎？
- 若要成文：缺哪一塊（外部驗證／機制故事／臨床掛鉤）？合理的目標期刊層級是哪一層？

## 提示（卡關再看）

<details><summary>提示 1：SCP1039 metadata</summary>
Broad SCP1039 的 metadata csv 有每顆細胞的病人、亞型與作者 celltype 欄位。讀入後 `AddMetaData` 對齊 barcode 即可；亞型資訊也可從原論文 supplementary table 的樣本表取得。先只用「病人、亞型」兩欄，celltype 欄留到對答案。
</details>

<details><summary>提示 2：CellChat 比較流程</summary>
按亞型 `subset()` 成兩個 Seurat 物件（細胞型別標籤要同一套 levels），各自 `createCellChat` → 標準流程 → `mergeCellChat(list(ER = ..., TNBC = ...))`，再用 `rankNet`、`netVisual_diffInteraction` 比較。族群細胞數太少（<10）的先併粗或剔除，否則通訊分數不穩。
</details>

<details><summary>提示 3：組成 vs 通訊的混淆</summary>
CellChat 的訊號強度和該族群細胞數有關。檢查法之一：對兩個亞型各自下採樣到相同的細胞型別組成再跑一次，看差異是否還在。至少要在發表路徑評估裡討論這個風險。
</details>
