# 細胞標注 · 參考庫

**所有資源均經網路逐一查證**（官方頁/GitHub/文件實際打開確認；規模數字為頁面實見，標「未確認」者表示官方頁未直書）。

## 這個資料庫是什麼

細胞標注（cell type annotation）是單細胞分析中最吃「外部知識」的一步：你需要 marker 基因字典、參考圖譜、自動標注工具，還有腫瘤情境下的惡性判定與細胞狀態程式。這個資料庫把課程與題庫會用到的標注資源統整成兩層：**精選**（第一線資源，日常分析從這裡選就夠）與**延伸**（什麼情況值得跳出精選去用它）。兩層都在這一份檔案裡。

## 先記住三條鐵則

1. **自動標注是假設，不是答案**（Q2・註解）：任何工具吐出的標籤都要用 marker 圖（DotPlot/FeaturePlot）回頭驗證，並在筆記記下「工具、參考集、版本、日期」四件事——參考庫會更新，你的紀錄是唯一能重現的東西。
2. **在 GBM 這類腫瘤，惡性判定通常要靠 CNV 而不是 marker**（Q3・惡性判定）：腫瘤樣本先走 CNV 推斷（inferCNV/CopyKAT）搭配跨病人分群行為，再談細胞型別；marker 只能標微環境。
3. **參考集的本質決定它的極限**：celldex 那批是「bulk 純化族群」——大類穩、連續狀態與罕見型別弱；圖譜映射（Azimuth/HLCA）只認得參考裡有的型別——疾病特有狀態會被硬塞到最近的健康標籤（《實作篇》題庫 進階30 的核心教訓）。

## 怎麼挑：從你的資料問起

照順序問下去，每一步的答案會把你帶到下面某個資源。

**一、什麼物種？**

- 人或小鼠 → 往下走
- 其他物種 → [Cell Taxonomy](#a1-cell-taxonomycncb-ngdc)（34 物種）、[EBI SCEA](#a2-ebi-single-cell-expression-atlas)（21 物種）；多半要自建 marker 清單（找該領域圖譜論文的附表）

**二、樣本含腫瘤嗎？**

- 含腫瘤 → 先做惡性判定：[inferCNV](#11-infercnvcnv-推斷經典)／[CopyKAT](#12-copykataneuploidy-判定)／[scATOMIC](#13-scatomicpan-cancer-自動標注)（注意各自失效的癌種）；CNV 訊號弱時看 [Numbat / inferCNA](#b6-numbat--infercnainfercnv-官方點名的替代品)、[ikarus](#b7-ikarus)
    - 惡性細胞 → 用 [3CA meta-programs](#14-3ca--curated-cancer-cell-atlas腫瘤狀態程式總站) 或[原始論文附表](#d3-經典程式原始論文附表需要原始定義時)做狀態註解，打分用 [UCell / AUCell](#16-ucell--aucellsignature-打分雙件套)；查同癌種既有結果 → [TISCH2](#15-tisch2腫瘤免疫查詢站)、[CancerSEA](#d1-cancersea)
    - 微環境細胞 → 當成正常組織，走第三步
- 不含腫瘤 → 往下走

**三、組織在 Azimuth 的官方 reference 清單內嗎？**（PBMC／骨髓／肺／腎／胰／心／肝／脂肪／扁桃腺／皮質…）

- 在 → [Azimuth](#5-azimuth映射式標注) 先跑一輪當第一意見
- 不在，而且是腦組織 → [Allen Brain Cell Atlas](#10-allen-brain-cell-atlas腦專用)
- 不在，其他組織 → 用 [CZ CELLxGENE Discover](#7-cz-cellxgene-discover找參考的入口) 找該組織的圖譜（h5ad）自建參考；也可參考 [Tabula Sapiens](#8-tabula-sapiens人類泛器官)（人）或 [Tabula Muris](#a4-tabula-muris小鼠泛器官)（小鼠）

**四、流程是 R 還是 Python？**

- R → [SingleR + celldex](#3-singler--celldexr-首選)（PBMC 用 MonacoImmune、造血用 Novershtern、小鼠免疫用 [ImmGen](#a3-immgen小鼠免疫權威)、小鼠泛用 MouseRNAseq）＋ [scType](#6-sctype快速第二意見) 當第二意見；輕量替代 → [scCATCH](#b1-sccatch)、[clustifyr](#b2-clustifyr-clustifyrdatahub)
- Python → [CellTypist](#4-celltypistpython-首選)（免疫用 Immune_All_Low 起手）；想試基礎模型路線 → [SCimilarity](#b5-scimilarityfoundation-model-路線代表)

**最後一律做手動 marker 驗證**：[CellMarker](#1-cellmarker-20主站已升-30) 查文獻級 marker、[PanglaoDB](#2-panglaodb) 快速打分、[HPA Single Cell](#c6-human-protein-atlassingle-cell) 補蛋白質層級佐證、[UCSC Cell Browser](#c2-ucsc-cell-browser) 看同類研究的作者原始註解。

## Ⅰ. Marker 基因資料庫

### 1. CellMarker 2.0（主站已升 3.0）

- **網址**：https://bio-bigdata.hrbmu.edu.cn/CellMarker/
- **定位**：人工整理的文獻級 marker 字典——查「這個細胞型別有哪些 marker、出自哪篇文獻」的第一站。
- **規模**（2.0 論文實見）：26,915 markers、2,578 細胞型別、656 組織，共 83,361 筆「組織–型別–marker」條目，出自 24,591 篇文獻；人類 52,987 筆、小鼠 32,285 筆。
- **物種**：人、小鼠。**存取**：免費免登入；2.0 舊下載頁已 404，3.0 新站下載格式未確認。
- **適用**：手動驗證 cluster 身分、幫 scType/scCATCH 補字典。**不適用**：人鼠以外物種。
- **引用**：Hu C, et al. *NAR* 2023;51(D1):D870–D876。

### 2. PanglaoDB

- **網址**：https://panglaodb.se/
- **定位**：一張 TSV 就能下載的輕量 marker 表（8,286 筆關聯、178 細胞型別、29 組織），教學與快速原型首選。
- **物種**：人、小鼠。**存取**：免費；**marker 表停更於 2020-03-27**。
- **適用**：課堂示範、AddModuleScore 快速打分。**不適用**：2020 後才確立的型別/命名；正式研究單獨依賴它。
- **引用**：Franzén O, et al. *Database (Oxford)* 2019。

## Ⅱ. 自動標注工具與參考集

### 3. SingleR + celldex（R 首選）

- **網址**：https://github.com/SingleR-inc/SingleR ｜ celldex（Bioconductor）
- **定位**：逐細胞與 bulk 純化族群參考做相關性比對；R/Bioconductor 流程的標準做法。
- **celldex 參考集選擇表**（本質全是 bulk 微陣列/RNA-seq 純化族群）：

| 參考集 | 用在 |
|---|---|
| MonacoImmuneData | **PBMC 首選**（vignette 明言 best covers a typical PBMC sample） |
| HumanPrimaryCellAtlasData | 人類泛用第一輪（多組織、微陣列） |
| BlueprintEncodeData | 大類註記要穩的時候（標籤較粗） |
| DatabaseImmuneCellExpressionData (DICE) | CD4⁺ T 細胞亞群 |
| NovershternHematopoieticData | 骨髓/造血前驅（myeloid/progenitor 解析度最高） |
| ImmGenData | 小鼠免疫（亞型極細） |
| MouseRNAseqData | 小鼠泛用（腦、血、心…） |

- **適用**：cluster 或單細胞層級的第一意見。**不適用**：連續分化狀態、腫瘤微環境罕見型（bulk 參考的極限）；標籤永遠要 marker 回驗。
- **引用**：Aran D, et al. *Nat Immunol* 2019。

### 4. CellTypist（Python 首選）

- **網址**：https://www.celltypist.org/ ｜ pip install celltypist（v1.7.1，MIT）
- **定位**：logistic regression 預訓練模型庫——**77 個模型**，免疫最強（入門用 `Immune_All_Low`），也涵蓋肺（含 HLCA）、腸、皮膚、心、肝、胰島、腦、胎兒多器官、小鼠全腦等。
- **物種**：人為主，含小鼠、豬、獼猴模型。**存取**：免費，模型各約 1 MB。
- **適用**：Scanpy 流程、免疫/PBMC；可用自己的資料訓練自訂模型。**不適用**：模型清單外的組織（先查 models.json）。
- **引用**：Domínguez Conde C, et al. *Science* 2022;376:eabl5197。

### 5. Azimuth（映射式標注）

- **網址**：https://azimuth.hubmapconsortium.org/references/ （網頁版免安裝；R 版 RunAzimuth）
- **定位**：把你的資料映射到高品質參考圖譜上取得標籤＋信心分數；HuBMAP 官方工具。
- **官方 reference 15 個**：Human PBMC（161,764 cells，l1/l2/l3 三層標籤）、骨髓、肺 v1/v2（HLCA）、腎、胰、心、肝、脂肪、扁桃腺 v1/v2、胎兒發育、運動皮質（人/鼠）、Mouse Pansci。
- **適用**：資料落在清單內組織時最省事的高品質選擇（PBMC 尤其）。**不適用**：清單外組織；疾病特有狀態會被塞進最近的健康標籤（映射的極限，《實作篇》題庫 進階30 主題）。
- **引用**：Hao Y, et al.（Seurat v4）*Cell* 2021。

### 6. scType（快速第二意見）

- **網址**：https://github.com/IanevskiAleksandr/sc-type ｜ https://sctype.app/
- **定位**：免參考資料集、cluster 級全自動打分（內建 ScTypeDB：免疫/胰/肝/眼/腎/腦/肺/心/腸/肌/胎盤/脾/胃/胸腺/腎上腺）。
- **存取**：免費 GPL-3.0；`source()` GitHub 腳本使用（非正式套件，最後 release 2022）。
- **適用**：第一輪草標、教學展示、與 SingleR 交叉比對。**不適用**：罕見亞型、字典外組織；單獨當最終答案。
- **引用**：Ianevski A, et al. *Nat Commun* 2022。

## Ⅲ. 參考圖譜

### 7. CZ CELLxGENE Discover（找參考的入口）

- **網址**：https://cellxgene.cziscience.com/
- **規模**（首頁實見）：33M+ unique cells、436 datasets、2.7K+ cell types；Census 快照另見 44M+ 人類細胞。
- **存取**：免費；下載 h5ad（**rds/Seurat 支援棄用中**）；程式化取用走 Census（Python `cellxgene_census`／R `cellxgene.census`）。
- **適用**：幫任何組織找標準化參考圖譜、抓子集自建參考。**注意**：R 使用者要會 h5ad 轉檔（《實作篇》題庫 基礎20 就是練這個）。

### 8. Tabula Sapiens（人類泛器官）

- **網址**：https://tabula-sapiens.sf.czbiohub.org/ （下載走 CELLxGENE）
- **規模**（portal 實見）：1.1M+ cells、28 器官、24 位捐贈者；v1 為 *Science* 2022 正式發表，v2 仍是 preprint。
- **適用**：泛器官人類標注參考、跨器官同型別比較。**注意**：引用時標明 v1 或 v2。

### 9. HLCA（人類肺圖譜；《實作篇》題庫 進階30 同款）

- **來源**：CZ CELLxGENE HLCA collection（Sikkema 2023 *Nat Med*；核心 584,444 cells／107 人／14 datasets）
- **適用**：肺資料的映射參考（Azimuth Lung v2 同源）；也是「圖譜時代標注」的教學範例。**注意**：h5ad 約 5.6 GB。

### 10. Allen Brain Cell Atlas（腦專用）

- **網址**：https://brain-map.org/ （資料文件 alleninstitute.github.io/abc_atlas_access）
- **定位**：全小鼠腦/全人腦轉錄體圖譜（站上規模描述「Millions of cells. Thousands of types.」；SEA-AD 等子計畫數字見官方頁）。
- **存取**：AWS S3 公開、**免帳號**，h5ad 格式＋官方 Python 工具。
- **適用**：腦組織亞型標注（泛器官圖譜解析度不足時）。**注意**：舊網址 portal.brain-map.org 已轉址。

## Ⅳ. 腫瘤專用

### 11. inferCNV（CNV 推斷經典）

- **網址**：https://github.com/broadinstitute/infercnv ｜ Bioconductor 3.21 v1.24.0
- **現況**：**官方 README 已宣告停止支援**，點名替代品 inferCNA/CopyKAT/Numbat；Bioconductor 仍可正常安裝。
- **輸入**：count matrix＋cell annotations＋gene ordering file；reference 用 `ref_group_names` 指定正常細胞（無 reference 可設 NULL 用全體平均，官方警語：細胞組成要夠異質）。
- **適用**：課程示範與惡性判定第一輪（Q3・惡性判定 流程）。**注意**：正式研究加測替代品交叉驗證；subclustering 參數是關鍵。

### 12. CopyKAT（aneuploidy 判定）

- **網址**：https://github.com/navinlabcode/copykat
- **定位**：貝氏方法估 5MB 解析度 aneuploidy，自動分 tumor/normal 並偵測亞克隆。
- **限制**（README 明文）：**小兒腫瘤與血液腫瘤（CNA 少）會失效**；官方 workaround 是提供已知正常細胞或用 T cells 當錨點。
- **引用**：Gao R, et al. *Nat Biotechnol* 2021。

### 13. scATOMIC（pan-cancer 自動標注）

- **網址**：https://github.com/abelson-lab/scATOMIC （v2.0.3，維護中）
- **定位**：階層式 immune/stromal/cancer 標注＋惡性判定＋原發部位推斷；訓練於 19 癌種、外部驗證 13 種（median F1=0.99）。
- **適用**：清單內癌種的快速全自動標注、轉移瘤來源推斷。**不適用**：清單外癌種的來源判定。
- **引用**：Nofech-Mozes I, et al. *Nat Commun* 2023。

### 14. 3CA / Curated Cancer Cell Atlas（腫瘤狀態程式總站）

- **網址**：https://www.weizmann.ac.il/sites/3CA/
- **規模**（2024 更新論文實見）：124 datasets、40+ 癌種、5.54M cells；統一惡性注解＋inferred CNA＋**149 個 meta-programs**。
- **適用**：腫瘤細胞狀態註解的首選（Neftel GBM 四狀態等經典程式都整合在 Gavish 2023 *Nature* 的 41 個惡性 MP 體系，Supplementary Table 2 一份 XLSX 全拿）。**注意**：免登入下載；個別經典程式原始定義回各論文附表（Neftel 2019 Table S2、Tirosh 2016、Puram 2017——PMC 均有免費全文）。
- **引用**：Gavish A, et al. *Nature* 2023;618:598。

### 15. TISCH2（腫瘤免疫查詢站）

- **網址**：https://tisch.compbio.cn/ （舊網域已失效）
- **規模**（首頁實見）：190 datasets、6,297,320 cells、約 50 癌種；注解分 malignancy／major-lineage／minor-lineage 三層。
- **適用**：快速確認「這個 marker 在這個癌種的哪些細胞表現」、幫題庫腫瘤題找旁證。**不適用**：批次下載訓練資料（官方明言不提供 batch download）。
- **引用**：Han Y, et al. *NAR* 2023;51:D1425。

### 16. UCell / AUCell（signature 打分雙件套）

- **網址**：Bioconductor（UCell v2.8.0；AUCell v1.26.0，SCENIC 家族）
- **定位**：rank-based（UCell，Mann-Whitney U）／AUC-based（AUCell）的 gene set 打分——配 3CA meta-programs 或 MSigDB C8 用。
- **適用**：腫瘤狀態、任何 signature 的逐細胞打分。**注意**：打分只給「相對富集」，**不能單獨當惡性判定依據**（Q3・惡性判定 鐵則）。
- **引用**：UCell：Andreatta & Carmona 2021；AUCell：Aibar et al. 2017（SCENIC）。

這裡只收 Q 系列課程與練習題會碰到的延伸資源；完整的延伸清單在 Q 系列《實作篇》的參考庫。

## A. 跨物種與特殊物種

### A1. Cell Taxonomy（CNCB-NGDC）
- https://ngdc.cncb.ac.cn/celltaxonomy/ ｜ 3,143 細胞型別、26,613 markers、**34 物種**、387 組織｜免費
- **適用條件**：資料不是人也不是小鼠（斑馬魚、豬、獼猴…），或需要跨物種對齊細胞型別命名時——這是它相對 CellMarker 的最大差異。純人類情境用精選即可。
- 引用：Jiang S, et al. *NAR* 2023。

### A2. EBI Single Cell Expression Atlas
- https://www.ebi.ac.uk/gxa/sc/home ｜ **21 物種**、384 studies、10,051,914 cells｜免登入
- **適用條件**：需要「同一條 pipeline 重算、可跨資料集直接比較」的表達值與 marker（它是本庫中再處理標準化最徹底的入口）；以及非人鼠物種找參考。《實作篇》題庫 基礎16（斑馬魚）、《實作篇》題庫 進階52（E-CURD-46）都會經過它。

### A3. ImmGen（小鼠免疫權威）
- https://www.immgen.org/ ｜ 分選純化小鼠免疫族群的 microarray＋ULI RNA-seq＋scRNA｜網頁 browser 免費
- **適用條件**：小鼠免疫細胞要標到細亞型時的權威 marker 來源；celldex 的 ImmGenData 即源於此，想追單一基因在哪個族群表現就來官網查。

### A4. Tabula Muris（小鼠泛器官）
- figshare project 27733 ｜ FACS/Smart-seq2 44,879 過 QC ＋ droplet 55,656 過 QC，20 器官 7 隻鼠｜figshare 免登入，附 Seurat Robjects
- **適用條件**：小鼠非免疫組織的泛用參考（clustifyrdatahub 可直接載入）；與人類 Tabula Sapiens 成對照組。

## B. 工具類延伸

### B1. scCATCH
- https://github.com/ZJUFanLab/scCATCH ｜ CellMatch 庫：353 型別、686 亞型、184 組織、2,096 篇人鼠文獻｜CRAN v3.2.2
- **適用條件**：想要「每個標籤附文獻證據」的 cluster 級標注（寫報告要引出處時）；需先指定物種+組織，混合組織樣本設定要小心。

### B2. clustifyr（+ clustifyrdatahub）
- Bioconductor v1.21.0 ｜ 相關性比對：吃 bulk、微陣列、scRNA 平均 profile 或 marker 清單當參考
- **適用條件**：手上已有「自家標注好的同組織資料」想轉移標籤、或想用任意自訂參考時最輕便；沒有內建大型人類參考，要自備。

### B3. MSigDB C8（cell type signature gene sets）
- https://www.gsea-msigdb.org/gsea/msigdb/collections.jsp ｜ **866 gene sets**（版本 2026.1.Hs）
- **適用條件**：想用 UCell/AUCell/AddModuleScore 的「signature 打分」路線做標注佐證，而不是逐 marker 檢查時；也可幫 scType 補字典。單基因層級證據要回原始出處。

### B5. SCimilarity（foundation-model 路線代表）
- https://github.com/Genentech/scimilarity ｜ 訓練 7.9M cells／參考 23.4M cells、30 組織｜pip 可裝，模型 Zenodo 免費
- **適用條件**：資料找不到現成參考、想對照「全人類圖譜」搜相似細胞狀態時；屬進階選修（Python、建議 GPU）。小鼠與訓練域外組織不適用。
- 引用：Heimberg G, et al. *Nature* 2025。

### B6. Numbat / inferCNA（inferCNV 官方點名的替代品）
- Numbat：https://github.com/kharchenkolab/numbat （haplotype-aware CNV）；inferCNA 見 inferCNV README 連結
- **適用條件**：inferCNV 已停止維護——正式研究的 CNV 判定建議至少加測其中一個交叉驗證；Numbat 需要 allele 資訊（BAM），作業成本較高。

### B7. ikarus
- https://github.com/BIMSBbioinfo/ikarus ｜ Python 預訓練 tumor/normal 分類器（Genome Biology 2022）｜活躍度低
- **適用條件**：scanpy 流程想要「一鍵腫瘤細胞判定」的第二意見；務必與 CNV 法交叉驗證後才採信。

## C. 圖譜與入口延伸

### C1. Human Cell Atlas Data Portal
- https://data.humancellatlas.org/ ｜ 70.9M cells、11.3K donors、532 projects（首頁實見）
- **適用條件**：要找原始層級（raw matrix/loom）的人類多器官專案資料；當標注參考不如 CELLxGENE 方便（project 級下載、格式不一，部分專案有存取條件）。

### C2. UCSC Cell Browser

- **適用條件**：**看別人怎麼標**——每個 dataset 保留作者原始 cluster 命名與 marker；手動標注卡住時，找 3 個同組織研究對照他們的命名與 marker 是最快的解法。

- **適用條件**：特定論文的 study 資料與作者註解（題庫的 SCP259/SCP1039 都在這）；提醒學生準備 Google 帳號。

### C6. Human Protein Atlas：Single Cell
- https://www.proteinatlas.org/humanproteome/single+cell ｜ 154 細胞型別、1,175 clusters、34 組織｜免登入，TSV 下載
