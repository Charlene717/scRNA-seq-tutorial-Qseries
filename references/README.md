# 參考庫

分析卡住的時候，缺的往往不是程式碼，而是「該去哪裡查」。這裡把課程與練習題會用到的外部資源整理成四份清單，每一個資源都寫清楚**定位、規模、怎麼存取、什麼情況適用、什麼情況不適用、怎麼引用**。

| 清單 | 回答的問題 | 對應課程 |
|---|---|---|
| [01 細胞標注](01_細胞標注.md) | 這群細胞是什麼？marker 去哪查、自動標注用什麼、腫瘤怎麼判惡性 | Q2・註解、Q3・惡性判定 |
| [02 富集分析](02_富集分析.md) | 一串基因怎麼翻成生物學？基因集資料庫、GSEA/ORA 工具鏈、活性推斷 | Q3・富集、Q3・活性 |
| [03 資料庫與資料入口](03_資料庫與資料入口.md) | 要找「新的」資料時該去哪個儲存庫或圖譜站搜尋 | Q2・資料與 QC、練習題選題 |
| [04 工具目錄與學習資源](04_工具目錄與學習資源.md) | 做某種分析該用什麼工具？去哪裡繼續學？ | 全課程 |

每一份都分兩層：**精選**是第一線資源，日常分析從這裡選就夠；**延伸**收的是「什麼情況值得跳出精選」——跨物種、特殊組織、蛋白質佐證、替代工具之類。

## 怎麼用

- 每份清單開頭都有**鐵則**與一段「**怎麼挑**」，從「你手上有什麼」出發往下走，通常三、四步就會落到該用哪個資源；
  每個資源名稱都可以直接點，會跳到同一份檔案裡它自己的段落。
- 「怎麼挑」之後有一張**與課程／練習題的對應表**，可以反過來查：做到哪一段、該翻哪幾個資源。
- 資源的規模數字與網址都經過查證，但這類頁面變動很快。**引用之前花 30 秒打開官方頁確認版本，並在報告裡記下取用日期。**

## 這裡收的是精簡版

這四份是照 Q 系列教到的範圍挑的：精選全收，延伸只留課程與練習題會碰到的部分。空間轉錄體、raw FASTQ 上游流程、跨物種特殊資源這些 Q 系列沒教的，收在《實作篇》的完整版參考庫裡（四座庫共 111 個資源，含 `.xlsx` 表格版與各自的決策樹）：[B 系列 · references/](https://github.com/Charlene717/scRNA-seq-tutorial-Bseries/tree/main/references)。
