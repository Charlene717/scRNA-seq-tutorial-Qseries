# 富集分析 · 參考庫

**所有資源均經網路逐一查證**（官方頁/GitHub/Bioconductor 實際打開確認；版本與規模為頁面實見，標「未確認」者表示官方頁未直書）。

## 這個資料庫是什麼

富集分析是把「一串基因」翻譯成「生物學語言」的那一步，工具與基因集資料庫多到眼花。這個資料庫把 Q3・富集 會用到的資源統整成兩層：**精選**（第一線資源，日常分析從這裡選就夠）與**延伸**（什麼情況值得跳出精選去用它）。兩層都在這一份檔案裡。

## 先記住四條鐵則

1. **富集的輸入決定方法**（Q3・富集）：一串顯著 marker → ORA（超幾何）；完整排名的 DE 結果 → GSEA/fgsea（不要先切 p 值再丟 GSEA）；想給每顆細胞打分 → escape/AUCell/UCell；想推 TF/pathway「活性」→ decoupleR＋CollecTRI/PROGENy。
2. **統計單位往上游追**（Q3・差異表達）：富集結果的可信度取決於餵進去的 DE 排名——cell-level p 值灌水的 DE 做出來的富集一樣灌水；pseudobulk DE 才是進階題的標準輸入。
3. **背景基因集（universe）是最常見的隱形錯誤**：ORA 的背景要用「這份資料實際測到的基因」，不是全基因體——單細胞測不到的基因不該進背景。
4. **參數三件事照舊**：用了哪個資料庫哪個版本（MSigDB 2026.1？GO release 日期？）、哪個方法、哪個背景——寫進筆記，富集結果才可重現。

## 怎麼挑：從你手上的東西問起

先看你手上有什麼，再決定用哪一條路。

**你手上是什麼？**

- **一串 cluster marker（顯著基因清單）**
    - 快速探索 → [Enrichr](#15-enrichr)、[g:Profiler ＋ ShinyGO](#16-gprofiler--shinygo)（貼上即得）；多組清單一次比較 → [Metascape](#a1-metascape)；另有 [WebGestalt](#a2-webgestalt-2024)、[DAVID](#a3-david)
    - 要可重現的流程 → [clusterProfiler](#6-clusterprofiler富集主力) 的 `enricher` ＋ msigdbr（記得設 universe）
- **完整排名的 DE 結果（logFC 或 stat 排序）** → [fgsea](#7-fgseapreranked-gsea) 或 clusterProfiler 的 GSEA；基因集首選 [MSigDB Hallmark](#1-msigdb第一選擇)
    - GO 結果太冗餘 → [rrvgo ＋ REVIGO](#d1-rrvgo--revigo)
    - 圖要能見人 → [enrichplot](#8-enrichplot結果視覺化)
    - 桌面版操作習慣 → [GSEA 桌面版](#a4-gsea-桌面版broad)
- **想給每一顆細胞打 signature 分數** → [escape](#10-escape單細胞-gsea-一站式) 一站式，或單用 [GSVA／ssGSEA](#9-gsva含-ssgsea)、[UCell／AUCell](01_細胞標注.md#16-ucell--aucellsignature-打分雙件套)。這是打分不是檢定，結論要回到 cluster 或病人層級的統計
- **想推「活性」而不是「表現」**
    - TF 活性 → [decoupleR](#11-decoupler--decoupler-py活性推斷主力) ＋ [CollecTRI](#12-collectritf-regulon-資源)（官方已建議取代 [DoRothEA](#e1-dorothea)；用到 viper 時注意[授權](#e3-viper經-decoupler-使用時的授權注意)）
    - Pathway 活性 → decoupleR ＋ [PROGENy](#13-progenypathway-footprint)
    - Regulon 從頭推斷 → [SCENIC / pySCENIC](#14-scenic--pyscenicregulon-推斷)
- **Python 流程** → [GSEApy](#b1-gseapy)
- **想從蛋白質交互作用切入** → [STRING functional enrichment](#c1-string-functional-enrichment)；Reactome 專用工具 → [ReactomePA / ReactomeGSA](#c2-reactomepa--reactomegsa)

**基因集資料庫怎麼選？**

- 第一輪永遠是 [MSigDB Hallmark](#1-msigdb第一選擇)（50 個、低冗餘）＋ [GO BP](#2-gene-ontologygo)
- 訊號與代謝機制 → [Reactome](#3-reactome)（CC0）優先於 [KEGG](#5-kegg用之前先懂授權)（授權有三重限制）
- 主題新、社群策展 → [WikiPathways](#4-wikipathways)（CC0）
- 商用環境 → 避開 KEGG，改用 Reactome、WikiPathways 或 [STRING](#c1-string-functional-enrichment)

## 維護注意（2026-09 查證時的現況快照）

- **MSigDB 已到 2026.1（35,361 sets）且新增 C9 collection**（computational perturbation signatures, 62 sets）——教材寫「C1–C8」的地方要更新；Hallmark = 50 不變；下載需免費註冊，msigdbr 套件可免註冊取用。
- **KEGG 三重限制**：FTP 大量下載採訂閱制、REST API 限學術（≤3 請求/秒）、商用需購買授權；clusterProfiler 的 enrichKEGG 執行時連網抓資料。商用環境改用 Reactome（CC0）/WikiPathways（CC0）。
- **DisGeNET 已商業化**（disgenet.com）：免費層需學術申請，批量下載不再開放——舊筆記的「免費下載全庫」已不成立。
- **DoRothEA 官方已建議改用 CollecTRI**；**SCENIC R 版官方棄用**（用 pySCENIC，但其最新 release 停在 2022，新專案可看 SCENIC+）。
- **decoupleR 重心已移到 Python 版**（decoupler 2.2.0, scverse）；R 版（Bioconductor 2.17.0）仍可用但長期維護狀態不明。
- **ShinyGO 已到 0.86**（2026-08，Ensembl 115）；DAVID Knowledgebase v2025_2 仍維護但資料快照較舊。
- 本庫查證日期 2026-09-07；引用前開官方頁確認版本，並在報告記下資料庫版本與取用日期（鐵則 4）。

## Ⅰ. 基因集資料庫

### 1. MSigDB（第一選擇）

- **網址**：https://www.gsea-msigdb.org/gsea/msigdb/
- **版本規模**（實見）：Human v2026.1.Hs／Mouse v2026.1.Mm，共 **35,361 gene sets**。Collections：**H Hallmark 50**（低冗餘，GSEA 首選）、C1 位置 302、C2 curated 7,670（含 CP:Reactome/WikiPathways/KEGG legacy）、C3 調控目標 3,714、C4 computational 1,006、C5 ontology 16,283（GO+HPO）、C6 oncogenic 189、C7 immunologic 5,219、**C8 細胞型別 866**、**C9 perturbation 62（2026 新增）**。
- **存取**：官網下載需**免費註冊**；R 內用 `msigdbr` 套件免註冊直接取（tidy 格式、多物種）。
- **適用**：GSEA/ORA 的基因集主來源；單細胞第一輪永遠從 Hallmark 起手。**注意**：教材寫「C1–C8」處要更新成含 C9。
- **引用**：Subramanian 2005 *PNAS*；Liberzon 2015 *Cell Systems*（Hallmark）。

### 2. Gene Ontology（GO）

- **網址**：https://geneontology.org/
- **版本規模**（實見，release 2026-08-05）：**38,092 terms**（BP 23,974／MF 10,041／CC 4,077）、15,129,348 annotations、172 物種。
- **存取**：免費免註冊（OBO/GAF 2.2）；R 內經 org.db 註解包離線用。
- **適用**：BP 是 marker list ORA 的標配。**注意**：terms 冗餘度高——結果動輒上百條時用 rrvgo/REVIGO 去冗餘（延伸 D1），或改報 Hallmark。
- **引用**：Ashburner 2000 *Nat Genet*；GO Consortium 2023 *Genetics*。

### 3. Reactome

- **網址**：https://reactome.org/
- **版本規模**（實見）：**Version 97**（2026-06-30）；人類 **2,883 pathways**、16,423 reactions、11,694 proteins。
- **存取**：**資料 CC0（公有領域，商用亦可）**、免費免註冊；R 用 ReactomePA（延伸 C2）。
- **適用**：訊號傳遞/代謝機制解讀的首選免費庫——**KEGG 的合法替代品**；階層式結構適合從大類往下鑽。
- **引用**：Milacic 2024 *NAR*。

### 4. WikiPathways

- **網址**：https://www.wikipathways.org/
- **版本規模**（實見）：**2,090 pathways**（2026-08 release）；GMT 檔涵蓋 18 物種。
- **存取**：**CC0**，免費免註冊；clusterProfiler 直接支援（enrichWP）。
- **適用**：社群策展、更新快——KEGG/Reactome 沒收的新主題（疫苗反應、罕病通路）常在這；也是商用安全選項。
- **引用**：Agrawal 2024 *NAR*。

### 5. KEGG（用之前先懂授權）

- **網址**：https://www.kegg.jp/ ｜ 587 個 reference pathway maps（release 119.0，實見）
- **授權三重限制**（官方 legal 頁實見）：(1) FTP 大量下載＝訂閱制（學術也要）；(2) REST API 限學術使用者、**≤3 請求/秒**；(3) **商用必須購買授權**。clusterProfiler 的 `enrichKEGG`/`gseKEGG` 執行時上網抓 KEGG——學術可用、商業環境不可。
- **適用**：pathway 圖視覺化仍是它最漂亮（pathview 上色）；學術教學可用。**不適用**：商用專案、需要離線批量基因集的流程（改用 Reactome/WikiPathways 或 MSigDB C2 的 legacy KEGG 集）。
- **引用**：Kanehisa & Goto 2000 *NAR*。

## Ⅱ. R 工具鏈

### 6. clusterProfiler（富集主力）

- **網址**：Bioconductor（v4.20.0，BioC 3.23）｜官方書 biomedical-knowledge-mining-book
- **定位**：ORA＋GSEA 統一介面，吃 GO/KEGG/WikiPathways/Reactome（經 ReactomePA）/任意 GMT（`read.gmt`＋`enricher`/`GSEA`，配 msigdbr）。
- **適用**：Q3・富集 的教學主力；可重現流程的標準選擇。**注意**：ORA 記得設 `universe`＝資料實際測到的基因（鐵則 3）。
- **引用**：Wu 2021 *The Innovation*（clusterProfiler 4.0）。

### 7. fgsea（preranked GSEA）

- **網址**：Bioconductor（v1.38.0）
- **定位**：快速 preranked GSEA（multilevel 演算法，p 值解析度高）。輸入是「完整排名的基因向量」——pseudobulk DE 的 stat 排序直接餵。
- **適用**：DE→GSEA 的標準路徑；速度快適合多 contrast 批跑。**不適用**：只有顯著清單沒有排名時（那是 ORA 的事）。
- **引用**：`citation("fgsea")`（Korotkevich et al.）。

### 8. enrichplot（結果視覺化）

- **網址**：Bioconductor（v1.32.0）
- **定位**：clusterProfiler 生態的視覺化——dotplot、cnetplot、emapplot、gseaplot2 等，ggplot2 基底。
- **適用**：報告與投稿圖的標準產線；emapplot 的網絡圖是「去冗餘後總覽」的好選擇。

### 9. GSVA（含 ssGSEA）

- **網址**：Bioconductor（v2.6.6）
- **定位**：per-sample 的基因集打分（gene×sample → geneset×sample），四方法：gsva（預設）、ssgsea、zscore、plage。官方已支援 sparse dgCMatrix 與 SingleCellExperiment。
- **適用**：pseudobulk 樣本層級的 pathway 分數（接著做組間統計）。**注意**：cell-level 可跑但受 dropout 影響——逐細胞打分建議改 rank-based（UCell/AUCell）或用 escape 統一介面。
- **引用**：Hänzelmann 2013 *BMC Bioinformatics*。

### 10. escape（單細胞 GSEA 一站式）

- **網址**：Bioconductor（v2.8.0，MIT）
- **定位**：官方描述「bridging GSEA into scRNA-seq」——同一介面跑 ssGSEA/GSVA/AUCell/UCell 逐細胞打分＋視覺化，Seurat/SCE 相容。
- **適用**：教學上「逐細胞打分」的首選套件（一次比較四種方法）。**注意**：打分是描述，結論回到 cluster/病人層級統計（鐵則 2）。

## Ⅲ. 單細胞活性推斷

### 11. decoupleR / decoupler-py（活性推斷主力）

- **網址**：https://github.com/saezlab/decoupleR （R v2.17.0）｜PyPI decoupler v2.2.0（scverse）
- **定位**：統一介面跑多種活性推斷方法（ulm/mlm/wsum/aucell/gsea/ora/viper…），搭配 PROGENy/CollecTRI 資源。
- **適用**：TF 與 pathway「活性」的現行主流；cell-level 與 pseudobulk 皆可。**注意**：官方重心已移 Python 版（更快省記憶體）；viper 方法帶非商用授權。
- **引用**：Badia-i-Mompel 2022 *Bioinform Adv*。

### 12. CollecTRI（TF regulon 資源）

- **網址**：https://github.com/saezlab/CollecTRI （經 decoupleR/OmniPath 取用）
- **規模**（論文實見）：**1,186 TFs、43,175 signed TF–gene interactions**（整合 12 個資源）。
- **適用**：TF 活性推斷的字典——比直接看 TF 表現量可靠（TF mRNA 低表現、dropout 嚴重）。**注意**：DoRothEA 官方已明文建議改用 CollecTRI（DoRothEA 條目見延伸 E1）。
- **引用**：Müller-Dott 2023 *NAR*。

### 13. PROGENy（pathway footprint）

- **網址**：https://saezlab.github.io/progeny/ （Bioconductor；官方建議經 decoupleR 使用）
- **規模**：**14 條 pathways**（Androgen/EGFR/Estrogen/Hypoxia/JAK-STAT/MAPK/NFkB/p53/PI3K/TGFb/TNFa/Trail/VEGF/WNT），人＋小鼠。
- **定位**：用 perturbation 實驗的「footprint 基因」推 pathway 活性——比對 pathway 成員基因做 GSEA 更能反映「活性」。
- **引用**：Schubert 2018 *Nat Commun*；Holland 2020 *Genome Biology*（單細胞適用性）。

### 14. SCENIC / pySCENIC（regulon 推斷）

- **網址**：https://github.com/aertslab/pySCENIC ｜ cisTarget 資料庫 resources.aertslab.org/cistarget/databases/
- **定位**：從資料自己推 regulon（TF＋標的基因）再用 AUCell 打分——與 CollecTRI「查字典」互補的「從頭推斷」路線。
- **現況**（實見）：**R 版 SCENIC 官方棄用**；pySCENIC 最新 release 0.12.1（2022-11），維護緩慢，官方生態轉向 SCENIC+。
- **適用**：想要資料驅動的 regulon（進階）。**注意**：教材要註明維護現況；新專案評估 SCENIC+。
- **引用**：Aibar 2017 *Nat Methods*。

## Ⅳ. 網頁快速工具

### 15. Enrichr

- **網址**：https://maayanlab.cloud/Enrichr/ （免費免登入）
- **規模**：Ma'ayan lab 官方頁載 **225 個 gene-set libraries**；R 介面 enrichR 3.4；另有 FishEnrichr/FlyEnrichr/WormEnrichr/YeastEnrichr 物種版。
- **適用**：貼上 marker list 三十秒拿到跨庫總覽——課堂演示與快速探索首選。**不適用**：正式流程（無法設 universe、版本不可控——正式結果回 clusterProfiler）。
- **引用**：Chen 2013 *BMC Bioinformatics*；Kuleshov 2016 *NAR*。

### 16. g:Profiler ＋ ShinyGO

- **g:Profiler**：https://biit.cs.ut.ee/gprofiler/gost ｜ 資料對應 Ensembl 114（2026-04 更新）、**400+ 物種**｜g:GOSt ORA＋gprofiler2 R 套件｜引用：*NAR* 2023。
- **ShinyGO**：https://bioinformatics.sdstate.edu/go/ ｜ **v0.86**（2026-08-28 更新；Ensembl 115、925 物種）｜免登入，圖表現成｜引用：Ge 2020 *Bioinformatics*。
- **適用**：兩者都是「免登入、物種廣、可重現性中等」的網頁 ORA——非模式物種（g:Profiler）與要現成圖（ShinyGO）時特別好用。**注意**：報告要記下工具版本與查詢日期。

# 延伸（10 個，Q 系列用得到的部分）

這裡只收 Q 系列課程與練習題會碰到的延伸資源；完整的延伸清單在 Q 系列《實作篇》的參考庫。

## A. 網頁一站式平台

### A1. Metascape
- https://metascape.org/ ｜ 免費（open-access）｜多資料庫整合分析
- **適用條件**：**多個 gene lists 要一次比較**（它的 "meta" 就是 multi-list meta-analysis）——例如 8 個 cluster 的 marker lists 丟進去看共同與特有富集；單一清單用精選的工具就夠。
- 引用：Zhou Y, et al. *Nat Commun* 2019;10:1523。

### A2. WebGestalt 2024
- https://www.webgestalt.org/ ｜ ORA＋GSEA＋NTA 三方法、663,247 analyte sets、支援代謝體
- **適用條件**：需要**網頁版 GSEA**（不只 ORA）或做代謝體/多組學富集時——它是網頁工具中方法最全的。
- 引用：Elizarraras JM, et al. *NAR* 2024;52:W415。

### A3. DAVID
- https://davidbioinformatics.nih.gov/ ｜ Knowledgebase v2025_2（2025-12-31）仍維護
- **適用條件**：老文獻對照（大量舊論文用 DAVID，重現/比較其結果時）；功能分類（clustering）視角。**注意**：內建資料快照比 g:Profiler/ShinyGO 舊約一年，新分析不建議當第一選擇。
- 引用：Sherman BT, et al. *NAR* 2022（2021 update）。

### A4. GSEA 桌面版（Broad）
- https://www.gsea-msigdb.org/gsea/ ｜ v4.4.0（2025-03）｜下載需免費註冊
- **適用條件**：要跑「原祖版」GSEA（phenotype permutation、正式 ES/NES 報告）或教學演示 GSEA 原理時；日常單細胞流程用 fgsea 就好。
- 引用：Subramanian 2005 *PNAS*。

## B. Python 生態

### B1. GSEApy
- https://pypi.org/project/gseapy/ ｜ v1.3.1（2026-07）｜GSEA/prerank/ssGSEA/GSVA/Enrichr API 的 Python 實作（Rust 加速）
- **適用條件**：Scanpy 流程內做富集不想離開 Python 時的橋接；配 decoupler（精選 #11 的 Python 版）幾乎能覆蓋全部需求。

## C. 專用資料庫與服務

### C1. STRING functional enrichment
- https://string-db.org/ ｜ v12.5：12,535 物種、59.3M proteins｜**CC BY 4.0（商用可）**
- **適用條件**：marker list 想同時拿 **PPI 網絡＋跨庫富集**（GO/KEGG/Pfam/InterPro 一次回）時；非模式物種富集的救援站（物種覆蓋極廣）。

### C2. ReactomePA / ReactomeGSA
- Bioconductor｜ReactomePA：R 內 Reactome ORA/GSEA；ReactomeGSA：多組學/單細胞的線上 GSA 服務
- **適用條件**：clusterProfiler 流程要接 Reactome（enrichPathway）；ReactomeGSA 適合想把 Seurat 物件直接丟給線上服務做跨資料集比較時。
- 引用：Yu & He, *Mol BioSyst* 2016；Griss J, et al. *MCP* 2020。

## D. 去冗餘與視覺化

### D1. rrvgo ＋ REVIGO
- rrvgo：Bioconductor v1.24.0（語意相似度去 GO 冗餘）；REVIGO：http://revigo.irb.hr/ （免登入、開源）
- **適用條件**：GO 富集吐出上百條高度重疊的 terms 時——先去冗餘再放進報告（Q3・富集 踩雷區的標準解法）；rrvgo 可進可重現流程，REVIGO 適合快速互動。
- 引用：Sayols S（rrvgo）；Supek F, et al. *PLoS ONE* 2011（REVIGO）。
