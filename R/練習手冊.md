# Q 系列練習手冊：用兩份公開資料（以 GBM 為例），獨立完成一份 scRNA-seq 分析

十二支腳本（00–10，含 06a/06b）、兩份資料（加 TCGA bulk）、約兩個下午。做完之後，你會有一份從矩陣到 pseudobulk DE、GSEA、細胞通訊、軌跡、調控與反卷積的完整分析，每一步都有數字、理由與紀錄。

## 資料

| 資料 | 內容 | 用在 | 大小 |
|---|---|---|---|
| 10x GBM 5k | 一位病人的膠質母細胞瘤，Chromium 3' v3，5,604 顆（Cell Ranger 4.0.0） | Q2：01–03 | ≈ 30 MB |
| GSE84465（Darmanis 2017） | 4 位 GBM 病人 × 核心／邊緣，Smart-seq2，3,589 顆，含作者的細胞型別標籤 | Q3：04–06 | ≈ 20 MB |

兩份都是公開資料，`00_setup.R` 會自動下載；失敗時腳本裡有手動下載的位置。

## 開始之前

1. 安裝 R ≥ 4.3 與 RStudio。新建一個 RStudio Project（例如 `gbm-quickstart`），把 `R/` 資料夾複製進去。
2. `07_cellchat.R` 的 CellChat 與 `10_deconv_survival.R` 的 MuSiC 從 GitHub 安裝（`00_setup.R` 會處理）；SCENIC 需要 Python 的 pySCENIC。
3. `05_infercnv.R` 需要系統層的 JAGS（macOS `brew install jags`；Ubuntu `apt-get install jags`；Windows 從 SourceForge 安裝）。
4. 全程不要用 `setwd()`；所有路徑相對於專案根。
5. 每支腳本開頭都 `set.seed(1234)`；重跑結果應完全一致。

## 交作業的格式（給課程使用）

每支腳本交三樣東西：

1. `output/figs/` 裡該腳本產生的圖。
2. 一段方法段文字（100–200 字）：用了什麼參數、為什麼、濾掉／移除了什麼。範本在 Q2 P19。
3. 練習題的答案（每題 2–5 句 + 必要的圖或表）。

評分重點不是「跑得出來」，是「每個參數答得出為什麼」。

## 常見錯誤

| 症狀 | 原因 | 解法 |
|---|---|---|
| `Read10X` 找不到檔案 | 路徑指到 tar.gz 或上一層資料夾 | 指到含三個 .gz 檔的 `filtered_feature_bc_matrix/` |
| `Layers(obj)` 沒有 `counts` | Seurat v4 物件或 v4 語法 | 確認 `packageVersion("Seurat") >= 5` |
| `scDblFinder` 報錯 | 物件太大或缺 BiocParallel | `as.SingleCellExperiment()` 前先 `DietSeurat()` |
| `getGEO` 逾時 | 網路／GEO 暫時無法連線 | 手動下載 series matrix，用 `getGEO(filename = …)` |
| counts 與 metadata 對不上 | 細胞命名格式不同 | 印出 `head(colnames(cnt))` 與 `head(meta$cell)` 比對；調整 `paste()` 的分隔符 |
| inferCNV 抱怨 gene order | 基因名對不上座標檔 | 檢查 `rownames(cts)` 是 symbol；用腳本裡的 EnsDb 替代作法重建 |
| `AggregateExpression` 欄名有 `-` | Seurat 把群名的 `_` 改成 `-` | 腳本已用 `sub()` 處理；自訂群名時避免 `_` |
| DESeq2 說 counts 不是整數 | 加總到了 data / integrated 層 | 確認 `assays = "RNA"` 且物件已 `JoinLayers()` |
| CellChat `computeCommunProb` 極慢 | 細胞太多或群太多 | 每個樣本分開跑；`subsetDB` 先只用分泌型；群 < 20 顆先併掉 |
| `netVisual_*` 找不到路徑 | 路徑名稱拼錯 | 名稱以 `cc@netP$pathways` 印出的為準（大小寫、連字號） |
| `music_prop` 報 gene 不重疊 | bulk 用 Ensembl ID、單細胞用 symbol | 先把 bulk 的 rownames 換成 `gene_name` 並去重 |
| `GDCdownload` 逾時 | 網路 | 分批下載（`files.per.chunk = 20`）或改用 `TCGAbiolinks` 的 cache |

## 進階路線

做完十二支腳本後：

- 用 `03` 的 Neftel 分數，在 `05` 判定的惡性細胞裡比較核心 vs 邊緣的狀態比例（配對、以病人為單位）。
- 用 `06` 的 DE 結果，在 TCGA-GBM 的 bulk 資料裡看前十名基因是否與存活相關（B17 反卷積）。
- 用 NicheNet 反推 06 的 DE：邊緣惡性細胞上調的基因最能被哪個配體解釋？與 07 的 CellChat 對照。
- 用 BayesPrism 重做 08 §3 的反卷積，比較兩種方法估的巨噬比例。
